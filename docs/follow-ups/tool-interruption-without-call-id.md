# 대상 id 없는 도구 중단 뒤 턴이 진행 중으로 남음

`server.test.ts`의 "현재 허용 대기가 있어도 대상 id 없는 도구 중단으로 턴을 끝내지 않는다"에서 `inTurn: true`가 남는다(실제 transcript 7건에서는 보고되지 않음). 대상 호출을 확인할 수 없어 종료를 보류하기 때문이며, 단순 시각 fallback은 "이전 결과와 중단 사이에 다른 줄이 끼어도 새 허용 대기를 끝내지 않는다"의 순서에서 새 `?`를 `cancelled`로 바꾸는 것을 reducer 비교 실행으로 확인했다. 현재 ID 확인을 유지하고 같은 줄의 결과를 읽는 문제는 수정했으며, 실제 ID 누락 사례를 수집해 새 허용 대기를 보존하면서 현재 턴 종료를 확인할 수 있는 추가 신호를 찾는다.

# PRODUCT.md와 사무실 스펙이 Codex 연결을 다루지 않음

Codex 세션 연결은 README의 "Codex 연결 실험"에만 적혀 있다. `PRODUCT.md`와 `docs/specs/office-activity-view/spec.md`는 사용자와 대상을 Claude Code·Claude 데스크톱 앱으로만 적고 있다. 또 원본 이벤트 기록(`/api/events`)에는 연결하지 않은 Codex 세션의 프롬프트와 명령도 남는다(Codex hook이 저장소 전체에 걸리기 때문). 실험을 정식 기능으로 올릴 때 두 문서의 범위와 기록 정책을 함께 정한다(2026-11-08).

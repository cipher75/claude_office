# 개발 서버 재시작 뒤 페이지가 새로고침되면 재시작 안내가 나타나지 않음

**증상**: 서버 연결 끊김 안내는 나타나지만, 개발 서버를 다시 켠 뒤 화면이 복구되면 빈 사무실로 바뀌고 재시작 안내는 나타나지 않는 경우가 있다.

**확인한 근거**: 2026-11-10 별도 4749 next dev 서버와 agent-browser로 확인했다. 서버를 종료하자 '사무실 서버와 연결이 끊겼어요'가 나타났다. 같은 distDir와 포트로 다시 켜자 화면은 복구됐지만 '사무실 서버가 다시 켜졌어요'는 25초 동안 나타나지 않았다. office-view.tsx의 useOfficeState는 이전 instance를 useRef, 안내 여부를 useState에만 보관한다. office-activity-view 스펙은 instance 변경 시 사용자가 확인할 때까지 안내하도록 정하고 있다.

**추정 원인**: Next 개발 클라이언트가 서버 재시작 후 페이지 전체를 새로고침하면서 이전 instance와 안내 상태를 함께 잃는 것으로 추정한다. 화면이 살아 있는 상태에서 SSE의 instance만 바뀌는 경우를 다루는 단위 테스트로는 이 경로를 검증하지 못한다.

**시도한 조치**: 연결 끊김과 화면 재연결은 실제 브라우저에서 확인했고, 안내 배너 검증은 미통과로 구분했다. 실제 4747 서버는 재시작하지 않았고 앱 코드는 수정하지 않았다.

**다음 확인**: 브라우저 탐색 이벤트와 문서 생명주기로 전체 새로고침 여부를 먼저 확인한다. 재현되면 업무 상태를 저장하지 않는 기존 원칙을 유지하면서 이전 instance 식별자만 sessionStorage 등에 보관할지 검토하고, 전체 페이지 재진입을 포함한 검증을 추가한다.
